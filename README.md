# Alzheimer El Salvador
Sitio web de la Asociación Alzheimer de El Salvador

El objetivo principal es como respaldo en la nube, en sus versiones iniciales, y como guia de ejemplo para creacion de sitios basicos en Node.Js

El sitio ha sido desarrollado con las siguientes tecnologias
* HTML / CSS
* JavaScripts
* JQuery
* BootStrap
* MySQL
* Node.JS

Dependencias
* stringbuilder
* formidable
* nodemailer

Librerias Auxiliares
* validetta
* toast
* animate
